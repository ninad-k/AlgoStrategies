PineConnector Documentation

Complete guide to Rey Capital's production-grade trading automation platform

Core Features

🚀 Hybrid Architecture

Python FastAPI backend + Rust Trade Engine for ultra-low latency execution with ZMQ inter-process communication.

📊 Partial Take Profits

Multi-level TP with 6-state FSM. Close positions gradually at TP1, TP2, TP3 with breakeven protection.

📈 Trailing Stops

Profit-based activation. SL moves automatically as price favors your position with step enforcement.

⏱️ Time-Based Exit

Auto-close positions after specified duration. Perfect for intraday and scalping strategies.

🛡️ Risk Management

7 protective gates: dedup, lot sizing, daily limits, max open per symbol, cooldown, equity protection, daily PnL limits.

📱 Real-Time Dashboard

Live trade monitoring, Rey Capital branding, dark/light theme toggle, and comprehensive analytics.

💡 Pro Tip

Start with dry-run mode to test your signals before trading with real money: python run.py --dry-run

Risk Management Gates

PineConnector includes 7 protective gates that validate every signal:

1. Deduplication (Dedup)

Prevents identical signals sent multiple times within 30 seconds.

Matching: action + symbol + lot
Status: "rejected" if duplicate found

2. Lot Size Gate

Validates position size constraints (min 0.01, max 10.0)

3. Daily Trade Limit

Maximum 20 trades per day (reset daily at 00:00 UTC)

4. Max Open Per Symbol

Prevents over-concentration (max 5 concurrent positions per symbol)

5. Cooldown Period

Minimum time between trades for same symbol (0 = disabled)

6. Equity Protection

Stops trading if drawdown exceeds 10% of peak equity

7. Daily PnL Limit

Stops trading if daily loss exceeds $500

⚠️ Important

All risk gates must pass for a signal to be executed. If any gate rejects, you'll receive a rejection reason in the API response.

Partial Take Profit Configuration

Automatically close portions of your position at different price levels with optional breakeven protection and trailing activation.

JSON Format

{
  "partial_tp": {
    "tp1_pips": 10,
    "tp1_percent": 50,
    "tp2_pips": 20,
    "tp2_percent": 30,
    "tp3_pips": 40,
    "tp3_percent": 100,
    "move_sl_to_be_on_tp1": true,
    "trail_after_tp2": false
  }
}

Plain Text Shorthand

buy,EURUSD,lot=0.10,sl=1.0850,tp1=10@50%,tp2=20@30%,tp3=40@20%

State Machine

Inactive
    ↓ [Signal received]
WaitingTP1
    ↓ [TP1 price hit]
TP1Hit (close 50%)
    ↓
WaitingTP2
    ↓ [TP2 price hit]
TP2Hit (close 30%)
    ↓
WaitingTP3
    ↓ [TP3 price hit]
Complete (close remaining 20%)

Trailing Stop Configuration

Automatically move SL upward as price moves in your favor, locking in profits.

JSON Format

{
  "trailing": {
    "enabled": true,
    "activation_pips": 20,
    "distance_pips": 10,
    "step_pips": 1
  }
}

How It Works

  1. Activation: Once trade is +20 pips in profit, trailing becomes active
  2. Tracking: SL moves up (for buy) or down (for sell) as price moves favorably
  3. Distance: SL always stays 10 pips away from current price
  4. Step: SL only moves if price movement ≥ 1 pip

Example: BUY Position

Entry: 1.0900
SL: 1.0850
Trailing: activation=20 pips, distance=10 pips

Price: 1.0920 (+20 pips) → Trailing activates
  SL: 1.0910 (price - 10 pips)

Price: 1.0930 (+30 pips)
  SL: 1.0920 (price - 10 pips, moved by 10 pips)

Common Trading Scenarios

Scalping Strategy (Short Duration)

buy,EURUSD,lot=0.5,sl=1.0880,tp=1.0920,time_exit_minutes=15

Quick 40-pip entry/exit with 20-pip SL. Auto-closes after 15 minutes.

Swing Trade (Breakeven Protection)

buy,EURUSD,lot=0.10,sl=1.0800,tp=1.1000,tp1=50@30%,tp2=100@70%,move_sl_to_be_on_tp1=true

Close 30% at first target, move SL to breakeven, then close 70% at second target.

Momentum Trade (Trailing Stop)

buy,XAUUSD,lot=0.5,sl=1900,tp=2000,trailing_enabled=true,trailing_activation=30,trailing_distance=15

Let trend run with trailing stop. Activate after 30 pips profit, lock in 15 pips.

Risk-Based Position Sizing

buy,EURUSD,risk_percent=2.0,sl=1.0850,tp=1.0950

Automatically calculate lot size based on 2% risk of account equity.

Quick Start Guide

1. Run the Platform

cd tools/pineconnector
python run.py

Server starts on http://localhost:8003

2. Test in Dry-Run Mode

python run.py --dry-run

All signals processed but no real trades executed.

3. Get Your Webhook URL

http://localhost:8003/webhook

Add this to your TradingView alert notifications.

4. Send Your First Signal

POST http://localhost:8003/webhook
Content-Type: application/json
X-Auth-Token: your_token

{
  "action": "buy",
  "symbol": "EURUSD",
  "lot": 0.10,
  "sl": 1.0850,
  "tp": 1.0950
}

5. Monitor Trades

Open http://localhost:8003 to see real-time dashboard with all trades.

6. Check API

GET http://localhost:8003/api/trades
GET http://localhost:8003/api/health
GET http://localhost:8003/api/analytics
